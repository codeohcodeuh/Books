---

## Purpose

Transform the current chapter-outline set from **Dev-Edit incomplete** into **Draft-Ready** status so scene outlining may begin.

This plan does **not** rewrite chapters.  
It specifies the smallest changes required for another editor to execute without further creative guidance.

---

## Hard Constraints (Non-Negotiable)

1. Do **not** add chapters.  
2. Do **not** add subplots.  
3. Do **not** increase Reveal Points (locked total = **14**).  
4. Do **not** alter the novel’s emotional philosophy (quiet, human-centered; cost > cool; compromise > nobility).  
5. Prefer the **smallest possible** change that resolves each issue.  
6. Hierarchy remains: Canon → Blueprint → Series Bible → Production Manual → Chapter Outlines → Scene Outlines → Prose.  
7. Word “Gumma” never appears on-page. Nuclear reveals remain 0.

---

## Philosophy Preservation Checklist

Every revision must still satisfy:

- [ ] Chapters begin with human problems, never institutional orientation  
- [ ] Invisible layer never becomes protagonist  
- [ ] Ch16 disappointment to both sides preserved  
- [ ] Ch22 non-extraction / empty guest mat preserved  
- [ ] Ch26 bodies agree before egos; Shankarappa absent from resolution  
- [ ] Ch29 unfinished sentence preserved  
- [ ] Ch27 crooked-stamp anticlimax preserved  
- [ ] Coda irreducible ambiguity preserved  
- [ ] Urban rhymes (parking / ESOP) remain mirrors, not competing A-plots  

If a proposed fix violates any item above → **reject the fix**, escalate to Creative Director.
